Midnight Vault — The Meridian Gallery Heist: a top-down heist game in plain HTML, CSS and JavaScript. Slip past the guards, grab the loot, keep the alarm meter down, and make the getaway. Demo presets stage the cover, alarm and getaway moments (`?demo=cover`, `?demo=alarm`, `?demo=getaway`).

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Build the hand-in dossier (Node 22, standard library only):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
